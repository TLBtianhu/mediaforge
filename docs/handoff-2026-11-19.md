## 1. 产品基线的主要整改

- 设置与共享配额使用完整 version 1 校验，拒绝缺失、旧、未来版本、未知字段和非法并发值。
- 音频组闭包校验由 O(N²) 降为 O(N)；同步查询与长任务使用分离的超时和进程回收语义。

### 6.2 本轮发现并修复的问题

1. **Windows 原生安装只允许 CUDA。** `src-tauri/src/runtime_assets.rs` 的 `installer_supports` 原来即使面对合法 CPU 描述符也返回 `RUNTIME_ASSET_UNAVAILABLE`。现已允许 CUDA/CPU，新增内嵌 CPU 清单选择与目标校验测试；真实 ZIP 安装证明修复有效。
2. **平台测试污染。** `LegacyRuntimeOverlayTests` 模拟 Linux 时，`platform.machine()` 将 Linux 写入进程级 `platform._uname_cache`，恢复 `sys.platform` 不会恢复该缓存，导致 Windows 上的 torch 错误进入 Linux `.so` 分支。相关测试类现在逐用例恢复缓存，不改变生产代码。
3. **首装脚本不支持 CPU 且诊断不足。** `scripts/smoke-first-install.ps1` 新增 `-Backend cuda|cpu`（默认 CUDA，保持 CI 兼容），显式隔离模型、运行时和 WebView 覆盖，并捕获失败时的原生 stdout/stderr。
4. **安装文档过时。** `docs/install-state.md` 已改为当前 `<安装根>\data/models/runtime-envs`、`app/` 程序布局、交互卸载的显式删除选项及 DSH bundle；README 的卸载说明也已同步。
