## 1. 产品基线的主要整改

- 设置与共享配额使用完整 version 1 校验，拒绝缺失、旧、未来版本、未知字段和非法并发值。
- 音频组闭包校验由 O(N²) 降为 O(N)；同步查询与长任务使用分离的超时和进程回收语义。
- 插件视图使用 URL fragment 会话和文档级 `MessageChannel`；导航关闭旧端口并拒绝未完成请求。
- 大媒体无 Range GET 上限为 16 MiB，Range 单段上限为 1 MiB；预览授权与目录句柄缓存有界。
- MCP 图像能力标识与重量级图像实现解耦，无 NumPy 的 bootstrap 也能启动工作流。
- Linux 运行时安装、激活和删除入口已开放到 Windows/Linux，但真实 Linux 环境尚未验收。
