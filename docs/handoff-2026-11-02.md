## 1. 项目是什么

MediaForge：Windows 桌面媒体处理应用（音频分离 + 图像/视频处理），Tauri 三层结构：

| 层 | 位置 | 说明 |
|---|---|---|
| 前端 | `src/`（Vue 3 + TS + Vite + Naive UI） | 组件自动导入，不要手写 Naive UI import |
| 后端 | `src-tauri/`（Rust） | 编排 worker、安装/升级、运行时资产、命令面 |
| Worker | `python/` | 进程内执行；音频核心在外部 `pymss` 包，图像/视频是自己的 `media_ops` |

分发有三种形态，**数据根必须互不相同**：

| 形态 | 程序位置 | 数据根 |
|---|---|---|
| 开发 | `src-tauri/target/{debug,release}` | 仓库 `.dev-data`（`scripts/dev.ps1`） |
| 便携 | 任意解压目录，带 `mediaforge.portable` 标记 | `<exe 目录>\data` |
| 安装 | `%LOCALAPPDATA%\Programs\MediaForge` | `%USERPROFILE%\.mediaforge` |

数据根可用 `MEDIAFORGE_DATA_ROOT` 覆盖（`src-tauri/src/storage.rs::data_root_dir`），
运行时资产在 `<数据根>\runtime-envs\<assetId>`，激活指针 `runtime-envs/active-runtime.json`。
